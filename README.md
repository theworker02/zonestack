# zonestack

Zone encode/decode helpers for stack payloads in pipelines.

**Site:** https://theworker02.github.io/zonestack/

## Install / run

```bash
git clone https://github.com/theworker02/zonestack.git
cd zonestack
node src/cli.js
node --test
```
